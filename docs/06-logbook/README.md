# 个人 Logbook 目录说明

## 命名规范

    YYYYMMDD_姓名_Logbook.md

例如：`20260000_张三_Logbook.md`

## 铁律

1. **48 小时原则**：任何工作完成后 48 小时内写入并提交。git 时间戳会自动证明你是当场写的。
2. **没有链接的记录等于没有发生**：每条记录必须带 PR / commit / Issue / 文档路径。
3. **不能有空周**：从 W1 到 W16，只要那一周你有投入，就必须有一行。
4. **每周日 21:00 前更新当周行**并提交。

## 推荐模板

```markdown
# 个人 Logbook —— 张三（R7 后端开发）

- 学号：xxxxxxxx
- GitHub：@zhangsan
- 负责模块：M3 库位管理、M7 通知、M9 盘点对账
- 覆盖周期：W01–W16

## 每周日志

| 周次 | 日期 | 任务编号 | 任务描述 | 起止 | 工时 | 状态 | 证据链接 | 协作 | 问题与解决 | 反思 |
|---|---|---|---|---|---|---|---|---|---|---|
| W08 | 2026-04-14 | T-42-03 | 实现库位状态机（空闲/占用/预留/停用）与非法迁移拦截 | 19:00-22:00 | 3.0 | 完成 | PR #57 | R8 Review | 并发下同一库位双占用 | 改用事务 + 库位唯一约束 |
```

## 组长的抽查记录

组长在每个 Sprint 末抽查 2 人，核对“日志里的链接是否真实存在”，结论写入
`docs/05-management/minutes/` 的会议纪要。
