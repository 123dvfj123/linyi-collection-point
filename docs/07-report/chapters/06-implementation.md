# 6. Design and Implementation

Design and implementation share a contract-first boundary. The OpenAPI contract was frozen before frontend feature work, so Vue pages and Spring services could be built in parallel; five paths were explicitly marked specified and not built rather than allowed to drift. The frontend uses one Axios wrapper and a tokenised status language: `tokens.css` defines semantic roles once, and `design-system.md` maps parcel, location, pickup and exception states to them, so meaning survives greyscale. The backend keeps state changes in services, uses Flyway for every schema change, and writes audit rows through one aspect. That made the handover and registration/shelving transactions reviewable in one place.
