# 7. Testing and validation

Twenty test classes hold eighty-seven backend test methods, twenty-seven of them Testcontainers integration tests that skip without Docker; the frontend adds sixty-eight. The last coverage measurement, 87.1 per cent of lines, predates pickup, so it is historical and JaCoCo enforces no gate. The most important defect came from tracing the model, not from a green test: handover tests inserted `shelved` directly, so they passed while the application could not reach that state. The missing path is now a recorded P0 defect and is fixed. Each pull request runs five jobs: commitlint, sanity, backend verify with Flyway, frontend lint/tests/build, and a Compose smoke test.
