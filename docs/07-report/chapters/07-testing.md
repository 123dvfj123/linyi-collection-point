# 7. Testing and validation

Twenty test classes hold eighty-seven backend tests, twenty-seven of them Testcontainers integration tests against PostgreSQL 16; the frontend adds sixty-eight. The post-merge run measures 88.8 per cent of lines and 64.6 per cent of branches; JaCoCo reports but does not enforce a gate. The most important defect came from tracing the model, not from a green test: handover tests inserted `shelved` directly, so they passed while the application could not reach that state. The missing path is now a recorded P0 defect and is fixed. Each pull request runs five jobs: commitlint, sanity, backend verify with Flyway, frontend lint/tests/build, and a Compose smoke test.
